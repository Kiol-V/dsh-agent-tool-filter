# Тест-отчёт релиза 1.1.1

## 01. Общие сведения

- **Версия:** 1.1.1
- **Дата тестирования:** 2026-10-26
- **Платформа:** DeepSeek Harness 0.2.1-rc.2 (десктоп-приложение)
- **Операционная система:** Windows 11 (10.0.22000), 64-bit
- **Node.js:** ^22.19.0 || >=24.0.0
- **Тестируемый пакет:** `dsh-agent-tool-filter` 1.1.1 (сборка из исходников репозитория)

## 02. Цель и объём тестирования

Проверка готовности релиза 1.1.1 (исправления и локализация). Объём: локализация панели апрува по языку интерфейса плагина (RU/EN, включая переключение на ходу), кроссплатформенный вызов esbuild в тестах и сборке, гигиена временных артефактов тестов; регрессия функций релиза 1.1.0 (мост апрува, ограничение инструментов).

## 03. Методика

- Автоматизированные тесты: 19 модулей (162 числовые проверки + 7 модулей сводки).
- Функциональное тестирование в десктоп-приложении: сценарии панели апрува на русском и английском языках интерфейса.
- Аудит безопасности: дельта к базе релиза 1.1.0 (поверхность изменений: тесты, сборка, словари локализации, панель).
- Контроль артефакта: пакет побайтово сверен с исходниками репозитория.

## 04. Проверенные сценарии и результаты

| Сценарий | Результат |
|---|---|
| Панель апрува на русском языке интерфейса: секции «Кто запросил / Обоснование / Что запрошено / Задание субагента», кнопки «Разрешить (один раз)» / «Отклонить» | пройдено |
| Переключение языка интерфейса на английский — панель переключается на ходу (Requested by / Justification / Requested action / Assignment, «Allow (once)» / «Reject») | пройдено |
| Разрешение (allow) — операция исполняется, результат проверен | пройдено |
| Отклонение (reject / Esc) — штатный отказ, субагент останавливается без обходных путей | пройдено |
| Сохранение языка панели после перезапуска приложения | пройдено |
| Регрессия: запрос расширенного доступа субагентом, раскрытие действия в панели, очередь запросов | пройдено |

Все сценарии пройдены; расхождений с ожидаемым поведением не зафиксировано.

## 05. Автоматизированные тесты

Все 19 модулей зелёные (162 числовые проверки + 7 модулей сводки), в том числе:

- словари локализации RU/EN — паритет 18 ключей панели апрува, резолв языка, валидация поля `language`;
- рендер панели — очередь, заглушки, фильтрация управляющих символов Unicode, ограничение размеров текста, локализация RU/EN;
- семантика моста апрува: однократное разрешение, отклонение, fail-closed при ошибках, отмена по сигналу, снятие при выключении тумблера, привязка аргументов к сессии запроса;
- конфигурация, write-API, маски фильтрации, remote-дескрипторы и строгие кодеки, сериализация конфигурации, клиентское хранилище запросов.

Дополнительно: изолированный прогон пакета (установка, композиция, запуск, удаление) — без ошибок; вызов esbuild в тестах и сборке — кроссплатформенный (определение типа бинарника по магическим байтам).

## 06. Аудит безопасности (дельта к базе 1.1.0)

Изменения релиза проверены по поверхностям базы: локализация не открывает новых путей инъекций (словари статические, недоверенные данные субагента — по-прежнему только в отфильтрованных текстовых полях); вызовы внешнего компилятора не принимают пользовательских данных; вывод диагностики компилятора чувствительных данных не содержит. Вердикт базы 1.1.0 (критичных и высоких находок нет) подтверждён; найденная находка низкой серьёзности (гигиена временных артефактов тестов) исправлена в актуальной версии.

## 07. Покрытие (что не проверялось)

- живые прогоны с субагентами глубины 2+ (внуки) — только автоматические тесты;
- поведение при отсутствии подключённого интерфейса (headless);
- нагрузочный сценарий множества параллельных запросов (очередь 10+);
- языки интерфейса, отличные от RU/EN.

## 08. Известные ограничения

- При активном системном диалоге платформы панель апрува временно скрыта до его завершения (запросы при этом копятся).
