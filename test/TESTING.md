## 1. Инструментарий

### Автотесты (в составе репозитория, этот каталог)

Запуск: `node repo/test/<module>.test.mjs` (каждый модуль самодостаточен, `node --test` не требуется).

| Модуль | Что проверяет |
|---|---|
| `config.test.mjs` | нормализация конфига: дефолты, матрица, профили, поле `language`, отбраковка |
| `restriction.test.mjs` | механика маскирования: `restrict()` поимённо, снятие масок, счётчик скрытых |
| `agent-filter.test.mjs` | применение фильтра: только корневые агенты, hot-update, валидация имени пресета |
| `compat-mode.test.mjs` | режимы auto/hide/block, детекция использования tools, guard |
| `serializer.test.mjs` | YAML-диалект insert-строк профиля, золотая форма, экранирование `!!js` |
| `manage.test.mjs` | write-API: связки, профили, копии/удаление пресетов, пакеты, `setLanguage` |
| `diagnostics.test.mjs` | статус, валидация имён, сводка предупреждений ✅/⚠/❌ |

| `remote-descriptors.test.mjs` | дескрипторы вызовов, строгие кодеки, опциональные параметры |
| `i18n.test.mjs` | словари RU/EN, резолв языка, валидация `language` |
| `preset-display.test.mjs` | display-тексты пресетов: словарь DSH, опубликованные метаданные, фолбэки |
| `client-render.test.mjs` | рендер UI-карточки: секции, модалки, статусы, локализация (SSR-смоук) |

## 2. Результаты

- **Автотесты:** 13/13 модулей зелёные (на момент релиза).
- **Приёмка:** 21/21 заданий пройдено.
- **Выявленные замечания и устранение:**
    - накопление статусов действий в макете (риск его поломки) → статус показывается под блоком, где было действие; активно только одно сообщение, авто-гашение (успех — 4 с, ошибка — 12 с);
    - статус в шапке уезжал из видимости (карточка выше экрана) → статус локализован под блоком действия;
    - инцидент 2026-10-17 «duplication of a tag property»: при копировании пресета выражение `!!js !ctx.get('profileContext')` записывалось без кавычек и ломало парсинг профиля → сериализатор экранирует такие выражения (запись в кавычках), повреждённый patch вылечен, добавлен регресс-тест (`serializer.test.mjs`) и проверка `verify-yaml.mjs`.
- **Персистентность:** связки матрицы, профили, копии пресетов, язык UI и состояние тумблера переживают перезапуск DSH (задание 21 приёмки).
