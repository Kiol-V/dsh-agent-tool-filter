# Тест-отчёт релиза 1.1.0

## 01. Общие сведения

- **Версия:** 1.1.0
- **Дата тестирования:** 2026-10-26
- **Платформа:** DeepSeek Harness 0.2.1-rc.2 (десктоп-приложение)
- **Операционная система:** Windows 11 (10.0.22000), 64-bit
- **Node.js:** ^22.19.0 || >=24.0.0
- **Тестируемый пакет:** `dsh-agent-tool-filter` 1.1.0 (сборка из исходников репозитория)

## 02. Цель и объём тестирования

Проверка готовности релиза 1.1.0 к использованию. Объём: новая функция расширенных прав субагентов (тумблер, панель подтверждения действия, семантика разрешений, параллельные запросы, отмена), регрессия функции ограничения инструментов, независимая и совместная работа двух функций, а также безопасность актуальной сборки.

## 03. Методика

- Автоматизированные тесты: 19 модулей (162 числовые проверки + 7 модулей сводки).
- Функциональное тестирование в десктоп-приложении: сценарии работы с субагентами при записи вне воркспейса через штатный запрос расширенного доступа (`sandbox_permissions` + обоснование).
- Аудит безопасности: профиль standard (базовые классы атак, AI/агенты, цепочка поставки, клиентская часть, протоколы/RPC, десктоп/IPC, ресурсы).
- Контроль артефакта: пакет, устанавливаемый в профиль, побайтово сверен с исходниками репозитория.

## 04. Проверенные сценарии и результаты

| Сценарий | Результат |
|---|---|
| Старт DSH, доступность чата | пройдено |
| Тумблер «Расширенные права субагентов»: включение и выключение в настройках плагина | пройдено |
| Запрос расширенного доступа субагентом: панель в чате родителя с раскрытием действия (пресет, сессия, задание, инструмент, аргументы вызова, обоснование) | пройдено |
| «Разрешить (один раз)» — операция исполняется, результат проверен | пройдено |
| «Отклонить» — штатный отказ, субагент останавливается без обходных путей, операция не исполняется | пройдено |
| Esc — отказ, эквивалентный «Отклонить» | пройдено |
| Три параллельных запроса — очередь с идентификацией каждого, исход каждого соответствует действию пользователя | пройдено |
| Остановка основного агента при висящей панели — панель остаётся до решения пользователя, запросы копятся, переключение между ними свободное | пройдено |
| Выключенный тумблер — эскалация не запрашивается, субагенты работают в обычном режиме | пройдено |
| Совместная работа функций — ограничение инструментов и расширенные права функционируют раздельно и вместе | пройдено |
| Отображение панели — блок ввода и кнопка Stop остаются доступными; порядок блоков: кто запросил, обоснование, операция, задание субагента | пройдено |

Все сценарии пройдены; расхождений с ожидаемым поведением не зафиксировано.

## 05. Автоматизированные тесты

Все 19 модулей зелёные (162 числовые проверки + 7 модулей сводки). Покрытие модулей:

- нормализация конфигурации, включая отклонение зарезервированных имён;
- write-API: связки пресет-профиль, профили, удаление имени (отклонение опустошения профиля);
- применение масок фильтрации;
- семантика моста апрува: однократное разрешение, отклонение, fail-closed при ошибках, отмена по сигналу, снятие при выключении тумблера, привязка аргументов к сессии запроса;
- клиентское хранилище запросов;
- рендер панели: очередь, заглушки, фильтрация управляющих символов Unicode, ограничение размеров текста;
- remote-дескрипторы и строгие кодеки;
- сериализация конфигурации.

Дополнительно: изолированный прогон пакета (установка, композиция, запуск, удаление) — без ошибок.

## 06. Аудит безопасности

Профиль standard, семь веток (базовые классы атак, AI/агенты, цепочка поставки, клиентская часть, протоколы/RPC, десктоп/IPC, ресурсы). Критичных и высоких находок нет; подтверждённые находки низкой серьёзности устранены в актуальной версии. Проверены и признаны закрытыми: отсутствие инъекций через данные субагента, невозможность самоодобрения запроса, отказоустойчивая семантика (fail-closed), отсутствие секретов в коде и конфигурации.

## 07. Покрытие (что не проверялось)

- живые прогоны с субагентами глубины 2+ (внуки) — только автоматические тесты;
- поведение при отсутствии подключённого интерфейса (headless);
- нагрузочный сценарий множества параллельных запросов (очередь 10+);
- коллизии идентификаторов вызовов провайдера (зависят от формата идентификаторов провайдера — не воспроизводились).

## 08. Известные ограничения

- При активном системном диалоге платформы панель апрува временно скрыта до его завершения (запросы при этом копятся).
